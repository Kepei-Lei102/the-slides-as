Collecting the nibble debt

"In two weeks you meet a number system with exactly 16 symbols. When you do, remember the nibble — the fit is not an accident."
— this room, two weeks ago
The fit: a nibble is 4 bits, and 4 bits have exactly $2^4 = 16$ patterns. Give each pattern one symbol and a nibble becomes a single character. That system is hexadecimal — base 16.
A=10, B=11, C=12, D=13, E=14, F=15. A hex digit is one of sixteen symbols; each has one matching 4-bit pattern.
A full 8-bit byte field uses two hex digits: 0000 0010 → 02. As a number, 2 and 02 have the same value.

↓ Same integer; different packing

011 010 110 → 326₈ and 1101 0110 → D6₁₆. Both mean 214. Fixed-size bit chunks work because 8=2³ and 16=2⁴.
Base 64 encodes a byte stream from the left. For 01001101: split 010011 |01, add zero bits on the right →010011 |010000. Indices 19 and 16 map toT andQ; padding gives TQ==.
Base 64 uses a 64-character alphabet and padding rules; it is not the same operation as writing an integer in another base. Three bytes normally become four characters.

Binary ↔ hex (no arithmetic allowed)

Binary → hex: group bits in fours from the right. Pad on the left if needed, then translate each group with the nibble table.

11010110 becomes:

1101D 01106 → D6

Hex → binary: expand each digit into 4 bits. For an 8-bit register, 02 →0000 0010. Without a stated width,10₂ also represents the value 2.
The trap: chunk from the right, pad the left. 1100111 → 0110 0111 → 67. Chunk it from the left and you invent a different number.

Field guide: where hex lives

Colours: #FF8800This RGB format uses 8 bits each for red, green and blue:255,136,0. It is one way to describe colour, not every screen’s format.
MAC: A4:83:E7:2C:5F:91A48-bit address written as six byte pairs. The prefix alone cannot prove a device is a particular phone.
Memory: 0x7FFC91A4Debuggers often display numeric memory addresses in hex; a dump may display the byte values stored there.
Error codes: 0x0000007BSome systems use hexadecimal identifiers for errors. The code has meaning only with that system’s documentation.
Unicode: U+4F60 = 你U+ notation writes a code point in hex. A code point is not the same thing as its encoded bytes in a file.
IPv6: 2001:db8::7334IPv 6 address groups use hex. The double colon compresses groups of zeroes; the full address has eight 16-bit groups.
The benefit: compact, readable representations that map directly to bit groups. Hex does not change the stored information.

↓ SHARED ENRICHMENT

↓ Three digits; a different engineering problem

8 =1×9 +0×3 −1×1: digits(+1,0,−1).
−8 =−1×9 +0×3 +1×1: digits(−1,0,+1).
Unsigned binary 8 is 1000: four bits rather than three trits. But a trit must distinguish three possible states; a bit distinguishes two. Counting digits alone ignores that cost.
Real choices depend on devices, noise margins, power, manufacturing and software. This example does not prove which hardware is cheapest.

An address is not a device biography

The syllabus model: a MAC address contains a manufacturer code and a serial code, usually represented in hexadecimal.
Modern practice: devices can use private, locally administered Wi-Fi addresses. A prefix is not reliable proof of the manufacturer or device model in every case.
For a question asking for the conventional structure, state that structure. For identifying an actual device, obtain more evidence.

BCD — encode the digits separately

8421 binary-coded decimal: give each decimal digit its own 4-bit code.
214 → 0010 0001 0100
Decode in groups of four:
0110 0000 1001 →6,0,9 →609
The same value 58:
ordinary binary 0011 1010 · hex 3A · BCD 0101 1000.
Each decimal digit is 0–9. A nibble 1010–1111 is invalid as a decimal digit in this encoding.

Where keeping decimal digits helps

Digit displays

A BCD nibble can enter a decoder/driver that controls seven display segments.

0101 → decoder → digit5

The decoder circuitry is essential; four wires do not directly specify seven segment states.

Decimal data

Decimal representations can preserve decimal quantities exactly within their precision.

Some systems use packed decimal; others use scaled integers or other decimal formats. Money does not imply one universal storage format.

0.1 has no finite binary fraction. The representation and rounding policy matter; floating-point detail comes later.
