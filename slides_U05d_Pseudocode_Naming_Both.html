One letter. Two possible contracts.

DECLARE Initial : CHAR
DECLARE Label : STRING
Initial ← 'R'
Label ← "R"
CHAR requires one character, written in single quotes.
STRING can have zero, one or many characters, written in double quotes.
"" is an empty STRING. It is not a CHAR.

AS: a calendar day is a value

DECLARE VisitDate : DATE
VisitDate ← 15/04/2027
DATE represents a valid calendar date. Here the format is dd/mm/yyyy.
31/04/2027 is not a valid calendar date.
"15/04/2027" is a quoted STRING; the DATE above is not quoted.
IG + AS

The right side is read first

DECLARE Count : INTEGER
Count ← 3
Count ← Count + 2
OUTPUT Count
Read old Count: 3 → calculate 3 + 2 → store 5.
Count ← Count + 2 changes the state; it is not an equation.
Count = 5 asks whether the values are equal. It does not change Count.

Input brings a value in. Output sends one out.

DECLARE TicketCount : INTEGER
OUTPUT "How many tickets?"
INPUT TicketCount
OUTPUT TicketCount
OUTPUT displays a message or value. A prompt does not store an answer.
INPUT TicketCount reads and stores the entered value in TicketCount.
For this task, assume the user enters a valid whole number.

Counter — complete reference

DECLARE Counter : INTEGER
Counter ← 4
Counter ← Counter + 3
OUTPUT Counter
Read old state 4; evaluate 4 + 3; store 7; output 7.
The arrow updates stored state. It is not an equation asserting 4 = 7.
