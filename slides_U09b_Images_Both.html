The smallest element of the image

Pixel · 像素: one image element with a colour value. We draw each as a square here.
Image resolution: width × height in pixels; or the total number of pixels.
A bitmap stores colour values with a defined order, so a decoder can rebuild the grid.

8 × 8 at 1 bit/pixel = 64 bits = 8 bytes of packed pixel data. The format must also tell us how to interpret it. Binary 0/1 choose the two colours.

How many bits per pixel?

Colour depth · 色彩深度: the number of bits used to represent the colour of each pixel.
With n bits, there are 2ⁿ possible codes. In a simple colour model, that permits up to 2ⁿ colours.
A picture need not use every permitted colour. More available codes are not more pixels.
DepthPossible colours
1 bit2
2 bits4
8 bits256
24-bit RGB16,777,216
An indexed image uses codes to look up a palette. An 8-bit image could use a palette or greyscale.

One common deal: three bytes for a colour

24-bit RGB: 8 bits for red + 8 for green + 8 for blue. Each channel has values 0–255.
“8 bits per channel” here means 24 bits per pixel. Read which quantity a specification is naming.
A common 32-bit RGBA layout adds 8 bits for alpha (transparency). It does not add eight extra RGB colour bits.

IG + AS

The formula, now that it means something

Width × height × bits/pixel = bits
Then ÷8 for bytes.
For KiB: bytes ÷1024.
For MiB: bytes ÷1024².
If depth arrives in bytes/pixel, multiply directly; do not divide by 8.
Worked together:
768 × 512 pixels at 24 bits/pixel.
768 × 512 × 24 = 9,437,184 bits
÷8 = 1,179,648 bytes
÷1024 = 1152 KiB
÷1024 = 1.125 MiB.

IG + AS

Two dials, different sacrifices

Double the width and height at the same depth → four times the pixel data. Halve both → one quarter. Halving width alone → one half.
Increase colour depth at fixed resolution → more possible colour values and more raw data. It can reduce colour banding when the source provides that detail.
In exam comparisons, higher original resolution/depth means more detail/colour fidelity. Upscaling or padding existing values does not guarantee newly captured information.
Actual file size also depends on compression, palettes, padding and metadata. It is not always the raw total plus a small header.

AS: MB and MiB are different requests

Same data: 1200 × 800 pixels, 3 bytes/pixel.
1200 × 800 × 3 = 2,880,000 bytes.
In MB: ÷1,000,000 = 2.88 MB.
In MiB: ÷1,048,576 ≈ 2.747 MiB.
Read the prefix. In AS, decimal and binary units are explicitly distinguished.

Header information can include width/height, colour depth, file/compression type and the data location. Exact fields depend on the format.
The same byte count can describe different grids. Without the format rules and metadata, a decoder cannot reliably reconstruct the image.

↓ Opened the box; could not decode the video

Container: organises streams and metadata. Codec: defines how a stream is encoded/decoded. A familiar extension alone does not promise playback.
In these MP4 files, the video sample description identifies the codec. Compatible brands describe compatibility; they are not a complete inventory of every stream.
Remux: copy encoded streams into another compatible container, without re-encoding. Transcode: decode and encode; cost and quality depend on the settings, and loss is not inevitable.
