The ladder starts where binary stopped

4 bits = 1 nibble · 2 nibbles = 1 byte · 8 bits = 1 byte
byte → KiB → MiB → GiB → TiB
From byte upwards, each step holds 1024 of the previous unit. Going up: divide. Going down: multiply.
Say it with units: 3 MiB = 3 × 1024 KiB = 3072 KiB.

Why 1024?

Ten binary address digits name 2¹⁰ = 1024 distinct patterns. That makes powers of two convenient capacities.
Investigate: a device implements only addresses 0–999. How many ten-bit patterns are unused? Does ten-bit addressing force every pattern to contain memory?
Check the idea

24 are unused. Address width bounds the number of distinct addresses; it does not force every address to be populated.

How big is an image?

A pixel is one picture element; colour depth is the bits used to describe its colour.
Uncompressed pixel data = width × height × bits per pixel. The result is in bits.
Our worked example: 512 × 512 × 16 = 4 194 304 bits.
÷8 → 524 288 bytes. ÷1024 → 512 KiB.
Keep the units beside each step. If depth is supplied in bytes, do not divide by eight again.
📝 IN THE EXAMCount pixels×depth; distinguish bits from bytes.
🏛 IN REALITYRaw pixels exclude headers, metadata and compression.

A sound file counts samples

A sample records the signal at one instant. Sample rate counts samples per second; bit depth gives bits per sample.
samples/second × bits/sample × seconds × channels → bits of uncompressed sample data.
For the following example, assume one channel. 22 016 × 8 × 10 = 1 761 280 bits.
÷8 →220 160 bytes; ÷1024 →215 KiB.
Two channels would double this payload. Headers and compression are separate from this count.

Then why is the saved photo smaller?

A 4000×3000 image at 24 bits has 36 000 000 bytes of raw pixels ≈34. 33 MiB.
